MEGA

Plays your MEGA cloud drive in Jellyfin. Files are decrypted on the fly (end-to-end), libraries are virtual: nothing is downloaded ahead, only small side files (subtitles, .nfo, posters).

    The password is used once to log in and is never stored: only the session is kept, in the plugin configuration of this server.

    Libraries

    Each entry maps a MEGA folder to a Jellyfin library. The plugin keeps a virtual copy of the folder (one small .strm file per video or song) and creates the Jellyfin library for you.

    Synchronization

    Duration, codecs and audio/subtitle tracks of new items (a few MB read per file).

    Thumbnails

    Images MEGA made at upload time: instant, no video read. Online artwork (TMDb…) still wins when found.
    Uses ffmpeg on the stream; reads a few MB of the file.

    Streaming

    Advanced
    Address ffmpeg uses to read MEGA files from this server. Empty = http://127.0.0.1:<port>. Changing it rewrites every .strm file.
    Clients always play through the normal Jellyfin endpoints, which keep the usual access control.
